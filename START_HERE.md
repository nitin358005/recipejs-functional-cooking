## ❓ Common Questions

**Q: Will my favorites be saved?**
A: Yes! They're saved in localStorage and persist after page refresh.

**Q: How does search work?**
A: It searches recipe titles AND ingredients. Try "egg", "oil", "pasta"!

**Q: Can I use search with filters?**
A: Yes! Search + Filter + Sort all work together.

**Q: What if the search is slow?**
A: It's not! Debounced at 300ms for smooth performance.

**Q: How many recipes are there?**
A: 8 total recipes. Counter shows how many match your filters.

**Q: Can I add my own recipes?**
A: Yes! Edit the `recipes` array in `app.js` (see QUICK_REFERENCE.md)

**Q: Works on mobile?**
A: Yes! Fully responsive. Try resizing your browser.

## 🐛 Something Not Working?

### Issue: Search not working
**Solution**: Reload page (Ctrl+F5) to clear cache

### Issue: Favorites not saving
**Solution**: Check browser allows localStorage (check privacy settings)

### Issue: Looking weird on mobile
**Solution**: Resize window wider, clear cache (Ctrl+Shift+Delete)
