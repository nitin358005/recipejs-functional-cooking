## 🎓 KEY CONCEPTS DEMONSTRATED

### 1. Pure Functions
```javascript
const applyFilter = (recipes, mode) => {
    // No side effects, same input = same output
    // Never modifies original array
}
```

### 2. Immutability
```javascript
const copy = [...recipesList];  // Shallow copy
copy.sort(...);                  // Sort copy, not original
return copy;                     // Return new array
```

### 3. Higher-Order Functions
```javascript
.filter((recipe) => recipe.time < 30)  // Takes predicate
.sort((a, b) => a.time - b.time)       // Takes comparator
.map(createRecipeCard)                 // Takes transform
.forEach((btn) => addListener(btn))    // Takes callback
```

### 4. Function Composition
```javascript
const updateDisplay = () => {
    const filtered = applyFilter(recipes, currentFilter);
    const sorted = applySort(filtered, currentSort);
    renderRecipes(sorted);
};
```
